# Solving Partial Differential Equations with Random Features

This github repository contains the numerical implementations accompanying the paper **Solving Partial Differential Equations with Random Features** by Chunyang Liao published in Communications in Nonlinear Science and Numerical Simulation, 2026, [[DOI]](https://www.sciencedirect.com/science/article/abs/pii/S100757042500752X?via%3Dihub). It includes the code used to generate the numerical results reported in the paper.
